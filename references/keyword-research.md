# 全库低价清单：关键词研究与实测结论

`data/lowprice_seed.json` 不是全库穷举，而是**关键词采样**的产物——微信读书没有「按价格浏览全库」的接口，只能靠搜索词命中。这份文件记录哪些词有用、哪些方向在低价档根本不存在，以及改词表前要盯的预算。

数据来源：`GET /web/search/name_books?keyword=&maxIdx=&count=40`，纯 JSON、可翻页，`books[].bookInfo` 直接带 `price`（元）、`newRating`（×100）、`newRatingCount`、`soldout`，**不必逐本查价**。已抽验与 `/web/book/info` 的 `centPrice/100`、`newRating` 一致。搜索页 `/web/search/books` 是服务端渲染，`maxIdx` / `page` / `offset` 全部无效，不能翻页——只能用上面那个接口。

过滤三种脏值：`price=0`（免费书）、`price=-1`（异常值）、`soldout=1`（已下架）。

## 时间预算

实测速率约 **0.53 秒/请求**（含 0.35 秒间隔与网络往返），补分类约 0.15 秒/本。

```
总时长 ≈ 请求数 × 0.53 / 60 + 命中本数 × 0.15 / 60
```

当前 222 词 / 904 请求 → 扫描 7.8 分钟 + 补分类 1.6 分钟 ≈ **9.4 分钟**。改词表前先算：

```bash
python -c "import sys;sys.path.insert(0,'scripts');from fetch_lowprice import GROUPS;print(sum(len(w)*p for _,p,w in GROUPS))"
```

**超过 950 就该砍词**，否则一轮破 10 分钟。`--pages-scale` 整体放大、`--pages` 统一覆盖，都直接改变这个乘积。

## 书名 vs 作者名（对照实验）

同样 4 页深度：17 个名著书名合计 21 本（每词 1.24 本），20 个对应作者名合计 28 本（1.40 本）。总量作者名略高，但结构完全不同：

- **作者名划算的前提是「一人多书、书名分散」**：凡尔纳 +4（八十天环游地球 / 地心游记 / 格兰特船长 / 海底两万里）、柯南道尔 +3、小仲马 +3、屠格涅夫 +1
- **单一代表作的名著，作者名归零**：莎士比亚 0、阿加莎 0、海明威 0、笛福 0、托尔斯泰 0（他的书已被书名《战争与和平》《复活》覆盖）
- 所以 `外国名著` 组是「书名为主 + 4 个多产作家」的混合，不做整体替换

**人名检索有弱相关噪音**：搜「韦伯」命中《长腿叔叔》（作者 Jean Webster）；搜「小仲马」命中几本无关成功学。报告保留「命中关键词」列，可据此判断。

## 关键词怎么来的

对已命中书名做 2–6 字 n-gram，再用**贪心集合覆盖**挑「一个片段能囊括最多书」的词，这就是「书名公约数」。工具：

```bash
python scripts/analyze_keywords.py                  # 贡献排行 + 零贡献清单 + 书名公约数
python scripts/analyze_keywords.py --min-cover 3    # 只看能覆盖 ≥3 本的片段
```

它给出三样东西：每个词实际命中几本、哪些词白花请求、哪些片段还没进词表。零贡献判断依赖种子 meta 里的 `keywordsUsed` 快照——没有快照会把新加的词误判成无效。

**加词的纪律**：先用 `--keywords 词1,词2 --no-enrich --out ./t.json` 小跑验证命中率，再决定是否进 `GROUPS`，不要直接全量重抓。

## 分类：纠偏与推断

平台 `category` 有两类问题，都在 `fetch_lowprice.py` 里处理，`--reclassify` 可只重算不重抓。

**纠偏（`CLASS_FIX`）**：平台分类明显不当，且只在该类白名单内才改，宁少不错。

| 原分类 | 纠正为 | 例子 |
|---|---|---|
| 历史 / 教育学习 | 国学古籍 | 道德经、论语、孟子 |
| 历史 / 教育学习 / 童书 | 古典文学 | 红楼梦、水浒传、三国演义 |
| 社会文化 | 法律法规 | 中华人民共和国票据法 |
| 经济理财 | 期刊杂志 | 雪球专刊系列 |

`《慎子》哲学宗教`、`《人类沉思录》哲学宗教`、`《人类简史》历史` 这类正常分类不会被改。原始值保留在 `platformType1`。

**推断（无分类时）**：平台对近 7 成低价书根本不返回 `category`，再查详情页也没有。按 **书名 → 作者 → 出版社** 的顺序归入最接近的微信读书一级分类，报告里分类名前加 **≈** 表示是推断值，种子里 `_type_src='inferred'`、`_type_infer_by` 记录来源层级。

推断规则的两条经验：

- **只用书名匹配，不要拼搜索关键词**。关键词是采样用的词，不是内容标签：掺进来会让 `传$` 这类锚点失效（《李鸿章传》被判成文学），也会把《心理学故事》因为关键词「哲学」拉到哲学宗教。
- **单字规则一定加边界**。`佛` 会命中「哈**佛**」，《哈佛教授讲述的 300 个心理学故事》就这样被判成了哲学宗教；改成 `(?<!哈)佛(?:教|学|经|法|典)` 才对。

规则咬不住的书用 `MANUAL_TYPE` 按 bookId 人工指定，优先级高于一切推断。当前只有一本：《我把一切告诉你1》（销售/职场题材，书名和作者里没有任何可判定的词），一级分类记 **经济理财** —— 销售/职场在微信读书里挂在它下面。这类目同样带 **≈**，因为仍然不是平台给的。

## 维护

- 刷新清单：`python scripts/fetch_lowprice.py`（默认 ≤2 元、评分 ≥70，约 9.5 分钟）
- 只补分类：`python scripts/fetch_lowprice.py --reclassify`（秒级）
- 放宽档位：`--cap 5 --min-rating 75`；想看更全：`--pages-scale 2`
- **不要用单轮全量结果直接覆盖种子**：搜索返回有波动，删过词的清单会丢掉只靠旧词命中的书，应「新全量 + 旧表独有」合并。
